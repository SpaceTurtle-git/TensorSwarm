Import from a URL

The Master downloads it once; workers then copy it over the lab network instead of the internet. Hugging Face: hf://datasets/owner/repo/path/file.csv

Using a dataset in code

import tensorswarm as ts          # already imported as ts in notebooks and jobs
root = ts.dataset("my-images")    # local folder, copied from the Master once
from torchvision.datasets import ImageFolder
data = ImageFolder(root / "train")

ts.download("https://…/file.zip", extract=True)   # straight from the internet, cached
ts.upload("checkpoints", "my-model")              # publish results back to the Master
  • Very large datasets (several GB): put them on the USB stick with prepare_usb.cmd -Datasets name, so no PC downloads them.
  • Versions are immutable. ts.dataset("name") means the latest; copy the pinned form to keep a run reproducible.
  • Use num_workers=0 in DataLoaders on Windows workers.
